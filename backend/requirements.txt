# ResearchMind AI — backend dependencies
#
# Runtime application dependencies only. Development tooling (Black, Ruff,
# mypy) is pinned separately in requirements-dev.txt, so a production
# install never pulls in tools it has no use for.
#
# Pinned to exact versions actually installed and tested against during
# development (see docs/architecture-decisions.md for the reasoning behind
# each major dependency choice — Ollama/Qwen3, ChromaDB, Sentence
# Transformers, Tavily, LangGraph, etc.).
#
# Transitive dependencies (torch, transformers, huggingface-hub, and so on)
# are intentionally NOT pinned here directly — they're resolved by pip from
# the top-level packages below, which is the correct place to own that
# resolution.
#
# NOTE for Phase 10 (Docker): installing `sentence-transformers` here pulls
# in PyPI's default `torch` wheel, which bundles CUDA runtime packages
# (nvidia-cublas, nvidia-cudnn, ...) even though EMBEDDING__DEVICE=cpu is
# the configured default and this project has no GPU requirement. That's a
# deliberate, deferred tradeoff (see ADR log) — the Dockerfile should
# install torch from the CPU-only wheel index
# (https://download.pytorch.org/whl/cpu) to avoid shipping ~1.5GB of unused
# CUDA libraries in the production image, rather than solving it here.

# --- Report export: PDF rendering ---
# Backs PDFReportExporter (app.reports.exporters.pdf_exporter). Distinct
# from pypdf above, which is read-only (used for extracting text from
# uploaded PDFs during ingestion) and has no document-composition API --
# ReportLab is this project's only PDF-writing dependency. Built on the
# Platypus layer (SimpleDocTemplate + flowables), not the low-level
# canvas API, so the exporter can compose paragraph/table/heading
# elements directly from a ReportDocument's structure. Pinned to
# 5.0.0 -- installed and smoke-tested (a real multi-element PDF built
# via SimpleDocTemplate/Paragraph/Table and confirmed to open with a
# valid %PDF-1.4 header) against this project's exact toolchain
# (Python 3.11, pillow 12.2.0, charset-normalizer 3.4.7, both already
# present from other dependencies and satisfying ReportLab's own
# pillow>=9.0.0 / charset-normalizer requirements with no conflicts per
# `pip check`). Declares `Requires-Python: >=3.9,<4` and is classified
# Development Status :: 5 - Production/Stable. The Platypus/lib.styles/
# lib.pagesizes APIs this project uses have been stable across the
# 4.x-to-5.0 boundary; the only user-visible change at 5.0 is that the
# optional C acceleration extension moved behind a `reportlab[accel]`
# extra instead of bundling by default, a performance-only concern for
# the single-document-on-demand PDFs this exporter generates, not a
# correctness or compatibility one.
reportlab==5.0.0
